# ZANKSTUDIO Visual Identity

Vite + React visual identity site for ZANKSTUDIO.

## Deployment
- Build command: `npm run build`
- Output directory: `dist`
- Framework: Vite

## Admin
Open `/admin` for the presentation control panel. Browser-side settings are stored locally; privileged server-backed editing requires a protected backend/CMS.

## Assets
All supplied visual assets are stored under `public/img`. The supplied source archive contained images and the supplied logo, but no video files.
